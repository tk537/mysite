LangChainを導入し、実際にAIアプリケーションを開発できる状態にするまでの手順を整理しました。

大きく分けて「環境構築」「パッケージ導入」「APIキー設定」の3ステップです。

1. 仮想環境の作成と有効化
Pythonプロジェクトでは、他のプロジェクトとライブラリが衝突しないよう、プロジェクトごとに仮想環境を作ることが推奨されます。

PowerShell

# 1. プロジェクトフォルダを作成して移動
mkdir my-llm-app
cd my-llm-app

# 2. 仮想環境 (.venv) を作成
python -m venv .venv

# 3. 仮想環境を有効化 (Windows)
.\.venv\Scripts\activate
# (Mac/Linux の場合: source .venv/bin/activate)
2. 主要パッケージのインストール
LangChainは機能ごとに細かく分かれています。用途に合わせて必要なものをインストールします。

PowerShell

# 基本セット (Core + OpenAI連携 + ユーティリティ)
python -m pip install langchain langchain-core langchain-openai langchain-community

# RAG（自前データ読み込み）をやる場合に追加
python -m pip install faiss-cpu tiktoken chromadb pypdf
3. 環境変数の設定 (APIキー)
OpenAIなどのモデルを使うためのAPIキーをOSに設定します。

Windows (PowerShell) の場合:

PowerShell

$env:OPENAI_API_KEY="sk-..."
Mac / Linux の場合:

Bash

export OPENAI_API_KEY="sk-..."
Tip: 開発が本格的になったら、プロジェクト直下に .env ファイルを作成し、python-dotenv ライブラリで読み込む方法が一般的です。

4. 導入確認テスト
以下のコードを test.py として保存し、実行して「Hello!」と返ってくれば導入成功です。

Python

from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage

# モデルの初期化
llm = ChatOpenAI(model="gpt-4o-mini")

# 実行
response = llm.invoke([HumanMessage(content="Hello!")])
print(response.content)
