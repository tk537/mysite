補足情報
バックスラッシュについて




2023年8月16日





バックスラッシュ（\）は以下のように入力してみてください。

Windowsでの日本語キーボードの場合 → 半角モードでキーボードの「ろ」を押す
macOSの日本語キーボードの場合 → Optionキーを推しながら「¥」を押す

もしくは「バックスラッシュ」を変換して半角記号を出すか、\をコピー＆ペーストしてもいいでしょう。なお、一部のWindowsのフォントでバックスラッシュは「¥」になることもあります（表示が変わるだけで動作していれば問題ありません）。

// ===== MyApp.java =====
public class MyApp {
  public static void main(String[] args) {
    System.out.println("Taro said hi. \n\"Hi!\", he replied.");
  }
}
