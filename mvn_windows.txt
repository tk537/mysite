2. Maven をインストールする方法（3通り）
方法①：公式ZIP（定番・確実）
① Maven をダウンロード
https://maven.apache.org/download.cgi

Binary zip archive を選択
例：apache-maven-3.9.x-bin.zip

② 展開
例：

3. 環境変数の設定（重要）
① JAVA_HOME の設定
例（JDK 17）：

JAVA_HOME = C:\Program Files\Java\jdk-17
② MAVEN_HOME（任意だが推奨）
MAVEN_HOME = C:\tools\apache-maven-3.9.x
③ Path に追加
以下を Path に追加：

%JAVA_HOME%\bin
%MAVEN_HOME%\bin
💡 PC 再起動 or 新しいターミナルを開く

4. mvn コマンドの動作確認
mvn -v
成功例：

Apache Maven 3.9.x
Java version: 17
OS name: "windows"
5. 基本的な mvn コマンド
プロジェクト作成
mvn archetype:generate
ビルド
mvn clean compile
テスト実行
mvn test
jar 作成
mvn package
依存関係ダウンロード（初回によく使う）
mvn dependency:resolve
6. よくあるエラーと対処
❌ 'mvn' は内部コマンドまたは外部コマンド…
原因：

Path が通っていない

再起動していない

✔ 対処：

MAVEN_HOME\bin が Path にあるか確認

新しいターミナルを開く

❌ JAVA_HOME is not defined correctly
原因：

JDK ではなく JRE を指定

パスが間違っている

✔ 対処：

javac -version が通るか確認

JAVA_HOME は jdk フォルダ直下

7. Eclipse / IntelliJ を使っている場合（補足）
Eclipse

Window > Preferences > Maven > Installations
IntelliJ IDEA

Settings > Build Tools > Maven
