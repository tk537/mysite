// ===== commentBox 1 =====
補足情報 bundlerに関するエラーが出る場合
2017年2月26日

Jekyllのインストールにはbundlerというgemが必要です。bundlerに関するエラーが出た場合は

gem install bundler


を実行してください。

// ===== commentBox 2 =====
補足情報 jekyll serveコマンドについて
2017年2月6日

Jekyll 4.3.0ではjekyll serveコマンドにはhostオプションをつける必要があります（ユーザーの方よりご指摘いただきました。ありがとうございます）。

ローカル開発環境のIPアドレスが192.168.33.10の場合は、

jekyll serve --host 192.168.33.10


としたのちに

http://192.168.33.10:4000/


にアクセスするようにしてみてください。
