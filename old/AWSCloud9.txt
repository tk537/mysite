// ===== commentBox 1 =====
補足情報 2021年1月現在の状況について
2021年3月14日

最初にAmazon Linux 2を選んだ場合、そのままではmysqlが起動しません。まずはMySQL互換であるMariaDBのサーバー版を導入します。

sudo yum -y install mariadb-server

としてください。

そのあとは0:49秒からの説明にあるとおり、viにて/etc/my.cnfを編集していきます。

sudo vi /etc/my.cnf

編集が終わったあとにcat /etc/my.cnfとすると以下のようになるはずです。

#
# This group is read both both by the client and the server
# use it for options that affect everything
#
[client-server]

#
# This group is read by the server
#
[mysqld]
# Disabling symbolic-links is recommended to prevent assorted security risks
symbolic-links=0


character-set-server=utf8mb4

[client]
default-character-set=utf8mb4


#
# include all files from the config directory
#
!includedir /etc/my.cnf.d


その後、MariaDBを次のコマンドで再起動します。

sudo systemctl restart mariadb.service

あとは

mysql -u root

にてMySQL（MariaDB）にログインできるはずです。

// ===== commentBox 2 =====
補足情報 初回アクセス時にActiveRecordのエラーが発生する場合
2019年7月3日

2019年2月21日現在、レッスン通りに rails s コマンドを実行してアクセスすると Active Record のエラーが出ることが確認されています。

解決するにはまず myapp ディレクトリにある Gemfile というファイルを開き、

gem 'sqlite3'


の行を、

gem 'sqlite3', '~> 1.3.6'


に変更して保存してください。

次に動画の 0:59 から説明している方法で起動中のサーバーを停止します。

そうするとターミナルにコマンドを入力できるようになるので bundle install というコマンドを実行し、完了したらもう一度 rails s でサーバーを立ち上げて、 Preview Running Application よりアクセスしてみてください。
