// ===== video_summary =====
.tmux.confを編集してPrefixキーを変更してみましょう。


    Prefixキーの変更
    .tmux.confの読み込み

// ===== read.me =====
# prefixキーの変更
vi ~/.tmux.conf
---- 編集開始
set -g prefix C-t
unbind C-b
bind C-t send-prefix

bind r source-file ~/.tmux.conf \; display "Configuration Reloaded!"
---- 編集終了

# 設定の再読込
Ctrl+b : source-file ~/.tmux.conf

# 設定の再読込
Ctrl+t r
