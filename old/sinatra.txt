// ===== commentBox 2 =====
補足情報 gem installについて
2019年10月14日

動画中、

gem install sinatra sinatra-contrib activerecord sqlite3 --no-document

のコマンドで Sinatra 関連の gem をインストールしていますが、レッスン収録時と現在でインストールされる gem のバージョンが異なるため、そのままではエラーが出てしまいます。

レッスンと同じバージョンの gem をインストールするには以下の手順を実行してください。

まずは

gem uninstall -I -a -x --user-install --force

としてインストールされている gem を削除し、

gem install sinatra -v 2.0.0 --no-doc
gem install sinatra-contrib -v 2.0.0 --no-doc
gem install activerecord -v 5.1.3 --no-doc
gem install sqlite3 -v 1.3.13 --no-doc

というコマンドを実行して gem をインストールし直してください。

// ===== commentBox 4 =====
補足情報 Rubyのバージョンアップをする方法
2017年8月19日

ドットインストールのレッスンで構築したローカル開発環境ではRubyのバージョン管理にrbenvを使っています。
もしバージョンアップをしたいなら、以下の手順をお試しください（Rubyのバージョンを2.4.1.にしたい場合）。

$ cd ~/.rbenv
$ git pull origin master
$ cd ~/.rbenv/plugins/ruby-build 
$ git pull origin master
$ rbenv install 2.4.1
$ rbenv global 2.4.1
$ rbenv rehash
$ ruby -v


上記のように作業をしてみてきちんとバージョンが上がっていれば作業完了です。

  database: './bbs.db'
)

end

  @comments = Comment.all
  erb :index
end

  redirect to('/')
end

end
