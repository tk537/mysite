// ===== commentBox 1 =====
補足情報
回転アニメーションについて




2024年11月28日





今回、指定している回転のアニメーションですが、以下のコードがなくとも同様に動作するようでした。
[data-aos="my-animation"] {
  opacity: 0;
  transition: opacity 300ms, transform 300ms;
}
これはtransitionに関しては、AOS内部で持っている設定（transition-duration: .4s）のほうが詳細度が高く、そちらが優先されているためでした。
独自のアニメーションを有効するには、セレクターの詳細度を上げる必要があるので、HTML、CSSに以下のような変更を加えてください。
HTMLの変更
独自のアニメーションをつけたい要素にid属性をつけます。
<img 
  src="forest.png" 
  width="240" 
  height="160" 
  data-aos="my-animation" 
  id="my-animation">
CSSの変更
セレクターにid属性を使って詳細度をあげます（以下の例では違いがわかりやすいように、3000msに設定しています）。
#my-animation {
  opacity: 0;
  transition: opacity 3000ms, transform 3000ms;
}

#my-animation.aos-animate {
  opacity: 1;
  transform: rotate(360deg);
}
