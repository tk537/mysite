コメントの上手な記述方法




2013年1月20日





なお、コメントは

--[[
print("hello")
--]]


としておくと、最初の--を---に変えるだけでコメントインすることができます。

---[[
print("hello") -- ここがコメントではなくなる
--]]


デバッグなどをする際にコメントアウト、コメントインをよく使う場合に覚えておくと良いでしょう。

// ===== hello.lua =====
-- comment
print("hello world")
print("hello world")
--[[
print("hello world")
print("hello world")
]]

数値、文字列の相互変換を行うにはtostring/tonumberを使いましょう。

x = tostring(x)

// ===== commentBox 1 =====
補足情報
関数をテーブルに格納する方法




2013年1月20日





関数はテーブルの一要素として格納することも可能です。
a = { f1 = function(a) print("this is "..a) end, f2 = function(b) print("that is "..b) end }
a.f1("Tom") -- "this is Tom"
a.f2("Steve") -- "that is Steve"

// ===== commentBox 2 =====

2013年1月20日

end

print(a) -- 2
print(b) -- 5

// ===== commentBox 3 =====
補足情報
関数の書き方について




2013年9月9日





なお、関数は文ではなくて、変数の型なので、
function f() {
  -- 処理
}

は、
f = function() {
  -- 処理
}

と書き換えることもできます。どちらの書き方にも慣れておきましょう

// ===== hello.lua =====
-- 関数、引数、返り値

function greet(name)
  -- print("hello! I am "..name)
  return "hello I am "..name
end

s1 = greet("Tom")
s2 = greet("Steve")

print(s1, s2)






// ===== video_summary =====
関数におけるローカル変数、可変引数について学びます。


    ローカル変数
    可変引数

// ===== hello.lua =====
-- 関数、ローカル変数、可変引数

--[[
function sum(a, b)
  local total = a + b
  return total
end

print(sum(2, 7))
print(sum(111, 2))
print(total)
]]

function sum(...)
  local a = {...}
  local total = 0
  for i = 1, #a do
    total = total + a[i]
  end
  return total
end

print(sum(2, 7))
print(sum(2, 7, 8, 9))
